# ROCK-R01G — Three.js-first licensed natural geometry pilot

**Approved design:** R01E A / Nordic Weathered Corestone.
**Rejected alternative:** prior ROCK-R01F's angular Boulder 01 and Blender studio R01G branch.
**Mission:** compare CC0 authored natural stones (Poly Haven Rock Moss Sets 01/02, Namaqualand Boulder 03) as genuinely sourced 3D geometry, then select one actual sub-mesh for a neutral WebGL art review against G1 and A.
**First stage:** source API provenance and geometry delivery feasibility. No geom generation, no Blender, no source model cloning into production.
**Source:** https://polyhaven.com/a/rock_moss_set_02 / https://polyhaven.com/a/rock_moss_set_01 / https://polyhaven.com/a/namaqualand_boulder_03
**Source rights:** https://polyhaven.com/license (CC0 for source models). API attribution/terms at https://polyhaven.com/our-api; do not treat hosted assets as proven Nordic geology.
**Quality veto:** no model is accepted just because it is scanned, legally available or renders successfully; require shape matching R01E A neutral form and no cliffs/mini-peaks/clear base skirt. Reject mismatch rather than mesh-warping it.
**Stop:** first complete neutral WebGL art review. No texture lookdev, world integration, merge or deployment.
