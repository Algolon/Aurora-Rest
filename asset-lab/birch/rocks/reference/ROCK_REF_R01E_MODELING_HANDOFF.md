# ROCK-REF-R01E — Modeling Handoff Contract (PLANNING ONLY)

**This file is NOT permission to model.** Start only when the owner explicitly approves a specific 2D option and a creation method. R01E is a 2D design gate.

## Creative requirements for the eventual artist

**Priority:** natural silhouette, continuous stone volume, varied geological surface regions, believable localized weathering joints, mass-based contact. Use Myrstigen photography for nonmirrored crack rims/erosion; use Kummakivi's bulk and 3D asymmetry only, not its balanced contact or geology. The eventual Aurora material will be a locally appropriate Nordic granite; Kummakivi is NOT a Bohus-granite lithology reference.

**Surface hierarchy to design, not tesselate:** one coherent crown/front/rear mass; broad exposed asymmetric natural form transitions; limited deeply weathered small crack lips. No mandated polygon quota. Triangles should only approximate an *already approved organic form*.

**Known vs inferred requirement:** existing photos do not show a reliable rear/right/top for the same Myrstigen stone. Artist should flag those as proposed design and obtain a multi-view visual art approval before believing this is real specimen reconstruction.

**Provisional object dimensions:** approximate 3–3.8 m width, 1.8–2.4 m visible height, 2.4–3.2 m depth. Set ground origin later. 2D shapes are not orthographically self-consistent; deliberately resolve perspective and unseen sides in a manual art pass.

## Recommended creation method: independent art-directed editable blockout

1. **Owner approves shape A/B/C and evidence limitations.**
2. Produce ONE editable manual blockout (Blender, equivalent direct artistic modeler, or manually authored brush/sculpt workflow); NOT a new Three.js ring-grid procedural boulder. Keep source .blend (or native editing equivalent) and intermediate neutral renders. Use no license-unclear photo displacement or scan.
3. Visual gate: front, front 3/4, right, rear 3/4, rear, top, ground contact and human-height neutral clay. Side-by-side with chosen 2D boards and G1 reference. Reject if there is a mini-mountain silhouette, clearly planar low-poly skirt or disconnected masses.
4. Allow **one** clearly scoped artistic correction if review explicitly authorizes it. If still poor, stop and change method, not an indefinite micro-sculpt loop.
5. After silhouette/large-surfaces art approval, clean retopology, finite normals/UV/color, optional T1 material, reproducible GLB export and runtime Three.js QA; respect resource disposal/instancing interface of F01. Set poly budgets by render profiling, not fictitious goals.
6. Final owner review must be separate from CI green tests, and there must be no merge, world placement, or deployment without new authorization.

### Optional alternative: licensed natural photogrammetry/scan
A fully covered **same-specimen** 3D scan might be useful, but no usable/licensed Myrstigen/Hunnebo scan has been verified. Only adopt after validating full viewing coverage, license explicitly permitting commercial derivatives, editable/retopologizable format, source provenance, and suitable scale. Two uncalibrated Kummakivi tourism photos are NOT photogrammetry-ready.

## Visual acceptance
At 5m: natural shallow weathering/local joint and believable contact; at 10m: distinctive single asymmetrical heavy mass; at 20m: strong uncluttered silhouette.
A must not look like an enlarged angular low-poly icon with extra normal maps.
