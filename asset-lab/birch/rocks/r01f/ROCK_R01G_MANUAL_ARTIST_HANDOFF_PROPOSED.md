# ROCK-R01G — Manual Artist-led Variant A Modeling Instructions (PROPOSED, NOT EXECUTED)

**User design approval already exists:** R01E **A / Nordic Weathered Corestone**, with Myrstigen weathering/joint and Kummakivi continuous mass. No new style choice required.
**Reason for new method:** G01–G02R procedural/panel loop never achieved geological authenticity; R01F licensed external 3D comparator was too jagged and not an A-shape match.

## Role
Work as a senior natural environment sculptor in **interactive Blender or comparable editable art tool**. Three.js is a REVIEW renderer and eventual runtime, not a replacement for geological sculpting. Do not give a Python-generated regular surface cage, convex cut polyhedron or shader-only black crack.

## Deliver exactly one first-pass pilot
- Native **.blend** (or actual editable modeling source), provenance notes, independent neutral renders.
- One heavy coherent boulder with broad, low asymmetrical crown and continuous mass (~3–3.8m width, ~1.8–2.4m visible height, ~2.4–3.2m depth, provisional). Resolve side/back artistically; reference photos do NOT document a 360° Myrstigen scan.
- Short and sheltered asymmetrical weathered joint (Myrstigen), large quiet surface/belly and uneven embedded support (Kummakivi provides mass not exceptional balancing support).
- Minimal details. Avoid texture first and avoid yet another arbitrary UVs/poly-triangle target.
- No production GLB integration, texture/lookdev, moss dressing, merge or deployment at this art stage.

## Process
1. Inspect owner-selected A 2D SVGs and R01C real photographs; label observed vs artist-inferred portions.
2. Author one manual mass silhouette, front and 3/4. Confirm it is distinctively wider/lower than the rejected R01F scan.
3. Continue the SAME continuous stone into side/rear/top, carving 3–5 coherent large geological surface zones.
4. Add only one locally shielded interrupted fracture with opposite rims non-mirrored.
5. Embed naturally via 2–3 broad uneven ground-bearing zones; no flat trimmed bottom ring.
6. Export only source + neutral photographic evidence (front, front 3/4, left, right, rear 3/4, rear, top, human height), with source dimensions, actual object counts and reviewers' concerns.
7. Stop. Owner art review before second correction, retopo, materials, Three.js preview or deployment.

## If no actual interactive sculpt tool
**Do not fabricate a Blender model or pretend programmatic triangle sculpting is manual art.** Limit to a verifiable artist-execution handoff and request an interactive Blender-capable session. A human-controlled Mac Blender session is a valid route. The assistant can review screenshots/GLB and run existing Three.js checks once an actual native source is supplied.
