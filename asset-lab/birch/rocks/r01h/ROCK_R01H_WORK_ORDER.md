## Mission
Identify **one real-world named glacial erratic or weathered boulder specimen** with full or useful 3D capture, traceable geological context, explicit license allowing derivatives and *actual accessible model bytes*. Test its potential for A before doing *any* modeling. Never call a Sketchfab embedded 3D viewer an acquired model.

## Minimum evidence gate
1. **Specimen identity:** named location/person, provenance of actual field object and scanned model author.
2. **Geometry:** scan from >=2 viewing angles ideally 360°, distinguishes boulder from base and vegetation, model/mesh format and size.
3. **Access & rights:** per-model license, public original downloadable model (not a ripped viewer), original format/GLB/OBJ/PLY with explicit commercial derivative permission. CC BY permitted with attribution; CC BY-NC, ND or unclear excluded for game use.
4. **Shape:** ONE continuous weather-rounded heavy glacial boulder, broad asymmetric silhouette, unlike the earlier artificial facet rocks. Other geological material is allowed as **mass inspiration only**, not a false Bohus granite label.
5. **Runtime:** only after meeting 1–4, import source into isolated Three.js GLTFLoader/PLYLoader/etc, with unchanged vertex positions, neutral clay / true WebGL. Any decimation is a separate provenance-documented technical action, never presented as a new sculpt.
